## 网络服务

| 服务 | 端口 | 说明 |
|------|------|------|
| **DHCP** | 67 | 支持 full / proxy / hybrid / off 四种模式，每个接口独立配置 |
| **ProxyDHCP** | 4011 | 叠加到现有 DHCP 环境，不影响客户端配置 |
| **TFTP** | 69 | 可配置端口和超时，提供 NBP 文件下载 |
| **HTTP** | 8080 | 提供引导脚本、Web UI、SPA、引导文件 |
| **DNS** | 53 | 本地 DNS 解析 + 上游转发，支持 A/AAAA/CNAME 记录 |
| **NFS** | 2049 | 内置 NFSv3，多挂载点，基于 IP 的访问控制 |

## 引导能力

### iPXE 支持

- 自定义编译 iPXE，嵌入式引导脚本
- 11 种 CPU 架构：x86 BIOS、EFI x86-64、ARM64 等
- Secure Boot 支持（x86_64 和 ARM64）
- 架构自动检测：根据 DHCP Option 93 客户端架构自动选择引导文件

### 引导类型

| 类型 | 说明 |
|------|------|
| **direct** | 直接加载内核 + initrd |
| **chain** | 链式加载到另一个 iPXE 脚本 |
| **wds** | Windows WDS 部署（WIM 文件） |
| **sanboot** | iSCSI SAN 引导 |
| **local** | 本地硬盘引导 |

### PXELinux 兼容

- pxelinux.cfg 格式解析器 + AST
- 自动生成 iPXE 脚本
- 无缝迁移到 iPXE

## 管理功能

### Web UI

- React 19 SPA，暗色/亮色主题
- 中英双语界面
- 实时数据刷新（SSE 事件流）
- 响应式设计，支持移动端

### REST API

- v1 版本，完整的 CRUD 操作
- JSON 请求/响应格式
- Cookie 会话认证
- `/api/v1/metrics` Prometheus 指标端点

### 主机管理

- 主机增删改查、分组
- 绑定 Profile（引导配置文件）
- MAC 地址管理
- 在线状态跟踪

### Profile 管理

- 引导配置文件，支持脚本版本管理
- 差异对比、回滚
- 支持 direct / chain / wds / sanboot / local 五种类型

### OS 安装目录

- 10 个预置 Linux 发行版分组
- 拖拽排序
- 自定义分组和条目
- 应答文件模板集成

### 应答文件模板

- 预设模板 + 自定义模板
- 支持预览和验证
- 变量替换
