# TFTP 服务

> TFTP 服务配置与架构映射。

**相关文档**: [架构映射](boot-settings.md) | [引导配置](../guides/boot-config.md)

---

TFTP 服务提供 NBP（Network Bootstrap Program）文件传输：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 端口 | 69 | UDP |
| 超时 | 默认值 | 客户端连接超时 |

Web UI：**基础配置 → 服务配置 → TFTP**

TFTP 服务根据架构映射自动选择正确的引导文件返回给客户端。引导文件内嵌在二进制中，首次运行时释放到数据目录。

---

## 引导文件管理

Web UI 中的 TFTP 页面包含引导文件管理 Tab 页签：

- **iPXE / PXELinux / GRUB2 三栏展示**：架构对应关系一目了然
- **上传文件**：手动上传自定义引导文件
- **删除文件**：删除不需要的引导文件
- **表格展示**：名称、大小、修改时间、MD5 哈希
