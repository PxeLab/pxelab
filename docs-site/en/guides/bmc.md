# BMC / IPMI Out-of-Band Management

> Remote server power management via IPMI protocol.

**Docs**: [Host Management](host-management.md) | [REST API Reference](../reference/api-reference.md)

---

Page path: `/bmc`

Remote server power management via IPMI protocol:

- **BMC Probe**: Discover IPMI devices on network
- **Device List**: DataTable showing all discovered BMC devices
- **Power Operations**: Power on / power off / restart
- **Boot Device Config**: Set boot device order
- **Batch Operations**: Apply power commands to multiple devices simultaneously
- **CSV Import**: Bulk import BMC configuration from CSV file
