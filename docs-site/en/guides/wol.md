**Docs**: [Host Management](host-management.md) | [REST API Reference](../reference/api-reference.md)

Remote power-on and scheduled wake functionality:

- **Wake History**: View past wake events
- **Scheduled Tasks**: Manage scheduled wake tasks
- **Create Schedule**: Set MAC address and wake time
- **Quick Wake**: Instantly wake any host by MAC
