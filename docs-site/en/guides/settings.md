# Settings

> Global application settings including network, services, OS installation, language, and advanced options.

**Docs**: [Service Config](services.md) | [DHCP Config](dhcp.md) | [TFTP Reference](../reference/tftp.md)

---

Page path: `/settings`

Global application settings with 5 sub-tabs:

- **Network**: Global network interface configuration
- **Services**: Global service settings (service ports, enable/disable)
- **OS Install**: Netboot catalog settings (local cache, catalog menu structure)
- **Language**: UI language selection (Chinese / English)
- **Advanced**: Advanced options (experimental features, debug settings)
