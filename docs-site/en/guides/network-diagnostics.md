# Network Diagnostics

> Network service detection and diagnostic tools.

**Docs**: [Service Config](services.md) | [Deployment](deployment.md)

---

Page path: `/diagnostics`

Network service detection and diagnostic tools:

- **Service Port Detection**: Check if all service ports are accessible
- **DHCP Server Detection**: Detect whether other DHCP servers exist on the network
- **TFTP Server Detection**: Detect whether other TFTP servers exist on the network
- **Conflict Resolution Suggestions**: Provide guidance on resolving detected conflicts
