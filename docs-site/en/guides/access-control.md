# Access Control

> MAC address-level network access control.

**Docs**: [DHCP Config](dhcp.md) | [Host Management](host-management.md)

---

Page path: `/access-control`

MAC address-level network access control:

- **Blacklist Tab**: Add/remove blacklist entries (MAC + reason)
- **Whitelist Tab**: Add/remove whitelist entries (MAC + subnet + reason)
- **Unauthorized Devices Tab**:
  - List devices not in any list
  - One-click add to whitelist or blacklist
  - Delete unauthorized records
