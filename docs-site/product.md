## 什么是 PxeLab

**PxeLab** 是一款一体化 PXE 网络引导服务器，将 DHCP、TFTP、HTTP、DNS、NFS 五大核心服务集成在单个二进制文件中，通过现代化的 Web UI 和 REST API 进行管理。

传统 PXE 部署需要分别安装和配置多个服务（DHCP、TFTP、HTTP 等），过程繁琐且容易出错。PxeLab 将这一切简化为一个可执行文件——下载、运行、开始使用。无论是批量装机、无盘工作站部署，还是日常服务器维护，PxeLab 都能提供高效、可靠的网络引导解决方案。

## 核心价值

| 价值 | 说明 |
|------|------|
| **零依赖部署** | 单二进制文件，无需安装额外依赖，下载即用 |
| **全架构覆盖** | 支持 11 种 CPU 架构，含 x86 BIOS/EFI、ARM64、Secure Boot |
| **现代管理界面** | 内置 React Web UI，暗色主题，中英双语，实时监控 |
| **灵活部署模式** | 4 种 DHCP 模式，适配各种网络环境 |
| **开箱即用** | 内置 iPXE、NFS、OS 安装目录，无需额外配置 |

## 方案对比

| 特性 | PxeLab | 传统 PXE（TFTP-only） | Foreman/Cobbler |
|------|--------|----------------------|-----------------|
| 安装复杂度 | 单二进制，零依赖 | 手动配置多个服务 | 需要大量依赖 |
| iPXE 支持 | 内置自定义编译 | 需自行编译 | 需自行集成 |
| 多架构 | 11 种 + Secure Boot | 通常仅 x86 | 有限 |
| Web 管理 | 内置，全功能 | 无 | 有，但复杂 |
| DHCP 模式 | full / proxy / hybrid / off | 通常仅一种 | 有限 |
| NFS | 内置 NFSv3 | 需外部 NFS | 需外部 |
| 平台支持 | Windows / Linux / macOS | 通常仅 Linux | 通常仅 Linux |
| 资源占用 | ≤ 512 MB 内存 | 取决于各服务 | 较高 |

## 快速体验

```bash
# 下载并运行
./pxelab

# 打开浏览器访问
open http://localhost:8080
```

首次启动后，PxeLab 会自动初始化默认配置。通过 Web UI 即可完成所有网络引导服务的配置和管理。
