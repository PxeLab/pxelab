# BMC 带外管理

> IPMI 带外管理，支持远程电源控制和 BMC 设备管理。

**相关文档**: [主机管理](host-management.md) | [WOL 网络唤醒](wol.md)

---

页面路径：`/bmc`

IPMI 带外管理页面：

- **BMC 配置列表**：DataTable 展示所有 BMC 配置
- **创建配置**：手动填写 BMC 地址、用户名、密码
- **CSV 批量导入**：上传 CSV 文件批量添加 BMC 配置
- **探测 BMC**：自动发现网络中的 BMC 设备
- **电源操作**：单台开机/关机/重启/状态查询
- **批量操作**：选择多台设备批量开机/关机/重启/查询状态
- **启动设备设置**：设置下次启动从 PXE / 磁盘 / BIOS 启动
- **刷新状态**：重新查询 BMC 连接状态
