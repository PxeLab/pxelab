# 应答文件模板（Answer Templates）

> 自动化安装的应答文件管理。

**相关文档**: [网络启动目录](netboot.md) | [安装任务](install-tasks.md)

---

页面路径：`/answer-templates`

自动化安装的应答文件管理：

- **模板列表**：DataTable 展示所有模板
- **创建模板**：选择预设模板或从空白创建
- **编辑模板**：在线编辑应答文件内容
- **预设模板库**：常见发行版的安装应答文件预设
- **验证**：语法和格式验证
- **预览**：生成最终应答文件预览
- **版本管理**：保存历史版本，支持回滚
