# 监控（Monitoring）

> 事件监控、审计日志和实时日志查看。

**相关文档**: [日志配置](../reference/logging.md) | [仪表盘](dashboard.md)

---

## 事件（Events）

页面路径：`/events`

实时事件监控页面：

- **SSE 实时流**：Server-Sent Events 推送新事件，支持暂停/恢复
- **类型过滤**：芯片按钮过滤 — 全部 / DHCP / TFTP / HTTP / BOOT / WOL / IPMI
- **分页**：服务端分页 + 客户端 SSE 缓冲
- **全屏模式**：支持全屏查看
- **事件列表**：时间、类型（带颜色标签）、MAC、消息

## 审计日志（Audit Logs）

页面路径：`/audit-logs`

所有配置变更的审计追踪：

- **审计记录列表**：DataTable 展示
- **列**：时间、操作类型（创建/更新/删除）、资源类型、资源名称、操作者 IP、变更详情
- **变更详情格式**：如 "名称: A→B; 架构: x86_64→arm64"

## 实时日志（Logs）

页面路径：`/logs`

多面板实时日志查看器：

- **SSE 实时流**：Server-Sent Events 推送日志，支持暂停/恢复
- **按服务过滤**：选择特定服务查看日志
- **颜色标签**：不同服务不同颜色
- **日志文件列表**：查看历史日志文件
- **磁盘占用统计**：日志占用空间
- **日志清理**：手动清理旧日志
