**相关文档**: [快速开始](../getting-started.md) | [DHCP 配置](dhcp.md) | [配置文件参考](../reference/config-file.md)

## 侧边栏导航结构

侧边栏分为四个分区，每个分区下的页面通过 `<Route>` 懒加载：

```
侧边栏导航
│
├─ 概览
│   └─ 仪表盘（/）
│
├─ 基础配置
│   ├─ 服务配置 ▸（二级子导航，显示在右侧）
│   │   ├─ DHCP（/services/dhcp）
│   │   ├─ DNS（/services/dns）
│   │   ├─ NFS（/services/nfs）
│   │   ├─ TFTP（/services/tftp）
│   │   ├─ Boot Settings（/boot-settings）
│   │   └─ Netboot 目录（/netboot-catalog）
│   ├─ 文件管理（/files）
│   ├─ 引导配置（/profiles）
│   ├─ 应答文件模板（/answer-templates）
│   └─ OS 镜像（/os-images）
│
├─ 管理
│   ├─ 主机（/hosts → /hosts/:id）
│   ├─ 访问控制（/access-control）
│   ├─ 安装任务（/install-tasks）
│   ├─ BMC（/bmc）
│   ├─ WOL（/wol）
│   └─ 网络诊断（/network）
│
├─ 监控
│   ├─ 事件（/events）
│   ├─ 审计日志（/audit-logs）
│   └─ 日志（/logs）
│
└─ 底部
    └─ 设置（弹出 SettingsModal 弹窗）
```

**注意**：「服务配置」是带二级子导航的分组，点击后在右侧展开子页面列表（DHCP / DNS / NFS / TFTP / Boot Settings / Netboot 目录）。

## 仪表盘（Dashboard）

首页仪表盘（`/`）提供全局概览，每 5 秒自动刷新：

**统计卡片**（顶行）：

| 卡片 | 数据来源 | 说明 |
|------|---------|------|
| 在线主机 | `hosts.last_online` | 最近 10 分钟内有记录的主机数 |
| 运行中服务 | `GET /api/v1/services` | status=running 的服务数 |
| 活跃租约 | Prometheus `dhcp.activeLeases` | 当前 DHCP 活跃租约数 |
| DNS 记录数 | `GET /api/v1/dns/records` | 总 DNS 记录数 |
| 今日引导次数 | events（type=BOOT, 今天） | 当天 BOOT 事件数 |

**服务状态栏**：显示 DHCP / TFTP / HTTP / DNS / NFS 五个服务的运行状态（绿/黄/红圆点）和端口。

**图表区域**：
- **流量趋势图** — TFTP / HTTP / NFS 带宽，支持 5m / 30m / 1h 时间范围切换
- **HTTP 状态码分布** — 饼图显示 2xx / 3xx / 4xx / 5xx 占比，支持时间范围切换
- **DHCP 架构分布** — 饼图显示各客户端架构（x86 BIOS / EFI x86-64 / ARM64 等）占比
- **最近事件** — 最新 12 条事件，带类型标签（DHCP / TFTP / HTTP / BOOT / IPMI / DNS）

**在线主机列表**：显示最近引导的主机，带在线状态圆点。

## 主机管理（Hosts）

### 主机列表（/hosts）

- DataTable 表格展示所有主机
- 支持搜索、分页、排序
- 列：名称、MAC、IP、Profile、引导次数、最后在线时间、在线状态
- 操作：新建、编辑、删除、跳转详情

### 主机详情（/hosts/:id）

进入单台主机的详情页，包含四个区域：

**1. 基本信息卡片**：
- MAC 地址、IP 地址、引导次数、最后在线时间、Profile 绑定、创建时间

**2. IPMI 电源控制卡片**：
- BMC 地址状态（已配置/未配置）
- 四个操作按钮：开机 / 关机 / 重启 / 查询状态
- 电源操作需确认弹窗（status 查询除外）

**3. 引导历史（DataTable）**：
- 按 MAC 过滤的事件列表
- 列：时间、类型（DHCP/TFTP/BOOT 等，带颜色标签）、消息

**4. WOL 历史**：
- 点击「加载」按钮拉取该主机的唤醒历史
- 列：广播地址、来源 IP、状态（成功/失败）

**顶部操作按钮**：
- **编辑** — 弹出编辑表单（名称、MAC、IP、Profile、BMC 地址、BMC 用户）
- **引导配置预览** — 选择格式（pxelinux / iPXE）预览该主机的引导配置
- **WOL 唤醒** — 一键发送唤醒魔术包

## 引导配置（Profiles）

页面路径：`/profiles`

管理所有引导配置文件（Profile）：

- **Profile 列表**：DataTable 展示，列包括名称、架构、是否默认、引导类型
- **创建 Profile**：弹窗表单，选择名称、架构（x86_64/arm64 等）、引导类型（direct/chain/sanboot/wds/local/custom）和对应参数
- **编辑 Profile**：修改引导参数
- **脚本版本管理**：每次修改 custom 类型脚本时自动保存版本快照
  - 版本列表：查看历史版本
  - 差异对比：比较当前脚本与历史版本的差异
  - 回滚：恢复到历史版本
- **从 Netboot 创建**：从 OS 安装目录一键生成 Profile

## 服务配置（Service Config）

二级子导航包含 6 个页面：

### DHCP（/services/dhcp）

- **子网配置**：每个子网独立设置 DHCP 模式（full/proxy/hybrid/off）、地址池范围、网关、DNS、租期
- **预留管理（Tab）**：IP + MAC 绑定，冲突检测，仅 full 模式子网可用
- **租约列表（Tab）**：查看当前活跃租约，支持删除和批量清理

### DNS（/services/dns）

- 上游 DNS 配置
- 本地域名设置
- DNS 记录管理（A / AAAA / CNAME）
- 子网感知解析配置

### NFS（/services/nfs）

- 多挂载点管理（动态卡片列表）
  - 添加/删除挂载点
  - 每个挂载点：标签、导出路径、本地目录、只读开关、IP/CIDR 白名单
- NFS 连接状态：当前连接数、客户端列表
- 端口配置

### TFTP（/services/tftp）

- 端口和超时设置
- 引导文件管理（Tab 页签）：iPXE / PXELinux / GRUB2 三栏展示架构对应关系
- 文件管理：上传、删除引导文件，表格展示（名称、大小、修改时间、MD5）

### Boot Settings（/boot-settings）

架构映射管理页面：

- **引导文件健康检查**：检查所有架构的引导文件是否存在、大小是否正常
- **架构映射表**：10 种架构的配置表格
  - 列：架构名称、AL 码、NBP 类型（iPXE/PXELinux/GRUB2 下拉切换）、引导文件名、Secure Boot 支持状态
  - NBP 切换时自动更新引导文件名
  - ARM64 + PXELinux 自动回退提示
- **iPXE 脚本设置**：自定义 iPXE 脚本（模板变量 `{{.URL}}` / `{{.MAC}}`）
- **操作**：保存、恢复默认值

### Netboot 目录（/netboot-catalog）

OS 安装目录管理：

- 发行版列表：显示所有可用发行版及其版本、架构
- 分组管理：10 个内置分组的启用/禁用、标题编辑、拖拽排序
- 缓存统计：缓存路径、文件数、磁盘占用

## 文件管理（Files）

页面路径：`/files`

管理引导文件目录中的文件：

- 表格展示：文件名、大小、修改时间、MD5 哈希
- 上传文件
- 删除文件
- 支持浏览引导文件根目录

## 应答文件模板（Answer Templates）

页面路径：`/answer-templates`

自动化安装的应答文件管理：

- **模板列表**：DataTable 展示所有模板
- **创建模板**：选择预设模板或从空白创建
- **编辑模板**：在线编辑应答文件内容
- **预设模板库**：常见发行版的安装应答文件预设
- **验证**：语法和格式验证
- **预览**：生成最终应答文件预览
- **版本管理**：保存历史版本，支持回滚

## OS 镜像（OS Images）

页面路径：`/os-images`

管理 ISO 镜像文件：

- **镜像列表**：DataTable 展示，列包括名称、大小、发行版类型、状态
- **上传 ISO**：拖拽或选择上传
- **导入本地文件**：指定服务器本地路径导入
- **操作**：解压、挂载、卸载、重新处理、删除
- **文件浏览**：浏览镜像挂载点内容
- **下载**：下载镜像文件

## 访问控制（Access Control）

页面路径：`/access-control`

MAC 地址级别的网络访问控制：

- **黑名单 Tab**：添加/删除黑名单条目（MAC + 原因）
- **白名单 Tab**：添加/删除白名单条目（MAC + 子网 + 原因）
- **未授权设备 Tab**：
  - 列出不在任何名单中的设备
  - 一键添加到白名单或黑名单
  - 删除未授权记录

---

## 安装任务（Install Tasks）

页面路径：`/install-tasks`

跟踪和管理网络安装任务：

- **任务列表**：DataTable 展示所有安装任务
- **创建任务**：选择发行版、版本、架构、目标主机、应答文件模板
- **任务状态**：查看安装进度和状态
- **编辑/删除**：修改任务参数或取消任务

---

## BMC

页面路径：`/bmc`

IPMI 带外管理页面：

- **BMC 配置列表**：DataTable 展示所有 BMC 配置
- **创建配置**：手动填写 BMC 地址、用户名、密码
- **CSV 批量导入**：上传 CSV 文件批量添加 BMC 配置
- **探测 BMC**：自动发现网络中的 BMC 设备
- **电源操作**：单台开机/关机/重启/状态查询
- **批量操作**：选择多台设备批量开机/关机/重启/查询状态
- **启动设备设置**：设置下次启动从 PXE / 磁盘 / BIOS 启动
- **刷新状态**：重新查询 BMC 连接状态

---

## WOL 网络唤醒

页面路径：`/wol`

Wake-on-LAN 管理页面：

- **唤醒操作**：输入 MAC 地址 + 广播地址，一键发送唤醒魔术包
- **批量唤醒**：选择多台主机批量唤醒
- **唤醒历史**：查看所有唤醒记录（时间、MAC、广播地址、状态）
- **定时调度**：
  - 创建定时唤醒任务（指定 MAC + 时间）
  - 定时任务列表管理
  - 删除定时任务
- **接口信息**：查看支持 WOL 的网络接口

---

## 网络诊断（Network Diagnostics）

页面路径：`/network`

内置网络诊断工具页面，两个 Tab：

### Ping Tab

- 目标主机输入
- 参数配置：次数、包大小、TTL、间隔、超时、是否持续
- 流式输出：实时显示每个 ping 包的响应
- 统计摘要：发送/接收/丢失数、往返时间最小/平均/最大值
- 可选择出口接口

### Traceroute Tab

- 目标主机输入
- 流式输出：逐跳显示路由路径
- 每跳显示：序号、主机名、IP、各探测时间
- 可选择出口接口

---

## 事件（Events）

页面路径：`/events`

实时事件监控页面：

- **SSE 实时流**：Server-Sent Events 推送新事件，支持暂停/恢复
- **类型过滤**：芯片按钮过滤 — 全部 / DHCP / TFTP / HTTP / BOOT / WOL / IPMI
- **分页**：服务端分页 + 客户端 SSE 缓冲
- **全屏模式**：支持全屏查看
- **事件列表**：时间、类型（带颜色标签）、MAC、消息

---

## 审计日志（Audit Logs）

页面路径：`/audit-logs`

所有配置变更的审计追踪：

- **审计记录列表**：DataTable 展示
- **列**：时间、操作类型（创建/更新/删除）、资源类型、资源名称、操作者 IP、变更详情
- **变更详情格式**：如 "名称: A→B; 架构: x86_64→arm64"

---

## 实时日志（Logs）

页面路径：`/logs`

多面板实时日志查看器：

- **SSE 实时流**：Server-Sent Events 推送日志，支持暂停/恢复
- **按服务过滤**：选择特定服务查看日志
- **颜色标签**：不同服务不同颜色
- **日志文件列表**：查看历史日志文件
- **磁盘占用统计**：日志占用空间
- **日志清理**：手动清理旧日志

## 顶部栏功能

### 服务状态下拉

顶栏右侧的**服务状态指示器**，悬停/点击展开：

- 显示运行中 / 已停止 / 错误的服务数量
- 展开后显示所有服务列表（名称 + 端口 + 状态圆点）
- 每个服务可单独启动/停止/重启
- 一键全部启动/全部停止/全部重启
- HTTP 标记为 Core，禁止停止操作
- 5 秒自动轮询刷新

### 通知中心

顶栏的铃铛图标，点击展开通知面板：

- 实时推送系统通知
- 查看历史通知

### 搜索 / 命令面板（⌘K）

按 `⌘K`（macOS）或 `Ctrl+K`（Windows/Linux）打开：

- 快速导航到任意页面
- 显示最近访问的页面
- 搜索功能和设置
- 键盘快捷操作

### 语言切换

中/英文一键切换，设置保存到 localStorage。

### 主题切换

- 亮色 / 暗色 / 跟随系统 三态切换
- 主色选择（蓝色、紫色、青色等调色板）
- 圆角基准调节
- macOS 卡片风格开关

## 设置弹窗（SettingsModal）

点击侧边栏底部的「设置」按钮弹出全屏设置弹窗，包含 5 个分区：

### 通用设置（General）

- 服务器名称
- 监听地址（如 `:8080`）
- 数据目录路径
- API Token（支持复制、重新生成）
- 页面默认分页条数

### 引导菜单（Boot Menu）

- 默认菜单标题
- 超时时间
- 默认菜单条目管理（添加/删除/排序）
- 菜单条目类型和参数配置

### Netboot

- 启用/禁用 Netboot
- 安装目录跳转配置
- 目录菜单结构（分组排序、启用/禁用、标题编辑）
- 自定义 iPXE 脚本
- 本地缓存开关和缓存统计
- 失败提示开关

### 服务自启动（Services Auto-Start）

- 每个服务的自动启动开关
- 即时生效，无需保存按钮

### 日志管理（Logging）

- 日志级别（debug/info/warn/error）
- 日志文件路径
- 日志轮转配置：最大体积、保留份数、保留天数、gzip 压缩
- 清理检查间隔
