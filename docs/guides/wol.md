# WOL 网络唤醒

> Wake-on-LAN 远程唤醒管理。

**相关文档**: [主机管理](host-management.md) | [BMC 带外管理](bmc.md)

---

页面路径：`/wol`

Wake-on-LAN 管理页面：

- **唤醒操作**：输入 MAC 地址 + 广播地址，一键发送唤醒魔术包
- **批量唤醒**：选择多台主机批量唤醒
- **唤醒历史**：查看所有唤醒记录（时间、MAC、广播地址、状态）
- **定时调度**：
  - 创建定时唤醒任务（指定 MAC + 时间）
  - 定时任务列表管理
  - 删除定时任务
- **接口信息**：查看支持 WOL 的网络接口
