# 设置（Settings）

> 点击侧边栏底部的「设置」按钮弹出全屏设置弹窗，包含 5 个分区。

**相关文档**: [配置文件参考](../reference/config-file.md) | [日志配置](../reference/logging.md) | [网络启动目录](netboot.md)

---

## 通用设置（General）

- 服务器名称
- 监听地址（如 `:8080`）
- 数据目录路径
- API Token（支持复制、重新生成）
- 页面默认分页条数

## 引导菜单（Boot Menu）

- 默认菜单标题
- 超时时间
- 默认菜单条目管理（添加/删除/排序）
- 菜单条目类型和参数配置

## Netboot

- 启用/禁用 Netboot
- 安装目录跳转配置
- 目录菜单结构（分组排序、启用/禁用、标题编辑）
- 自定义 iPXE 脚本
- 本地缓存开关和缓存统计
- 失败提示开关

## 服务自启动（Services Auto-Start）

- 每个服务的自动启动开关
- 即时生效，无需保存按钮

## 日志管理（Logging）

- 日志级别（debug/info/warn/error）
- 日志文件路径
- 日志轮转配置：最大体积、保留份数、保留天数、gzip 压缩
- 清理检查间隔
