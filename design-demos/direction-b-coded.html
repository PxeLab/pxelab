快速开始

PxeLab 是一个单二进制的一体化 PXE 网络引导服务器，内置 DHCP、TFTP、HTTP、DNS、NFS 五个网络服务。无需任何外部依赖，下载后即可运行，可引导 11 种客户端架构。

在 Linux 或 macOS 上，使用安装脚本获取最新版本：

terminal 
# 下载并安装 PxeLab
curl -fsSL https://pxelab.com/install.sh | bash

# 启动服务（需要特权端口，建议使用 sudo）
./pxelab

启动后，在浏览器中打开 http://localhost:8080 进入 Web 管理界面，即可配置引导菜单、管理客户端与镜像。

i
提示：PxeLab 默认监听 DHCP（67）、TFTP（69）等特权端口。在生产网络中部署前，请先确认网段内没有其他 DHCP 服务器，避免地址分配冲突。详见 config.yaml 中的 dhcp.subnet 配置。
