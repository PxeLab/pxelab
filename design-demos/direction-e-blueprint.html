快速开始

PxeLab 是单二进制的一体化 PXE 网络引导服务器。它在同一进程内运行 DHCP、TFTP、HTTP、DNS 与 NFS 五个网络服务，并附带一个 Web 管理界面。下载、运行、打开浏览器 —— 三分钟即可引导第一台机器。

§1.1安装

在 Linux 或 macOS 上，使用安装脚本获取最新版本。脚本会将单个静态二进制放入 /usr/local/bin，无其他依赖。

TERMINAL — INSTALLSH
# download & install the latest release
curl -fsSL https://pxelab.com/install.sh | bash

§1.2运行

直接启动即可。PxeLab 会监听 DHCP :67、TFTP :69、HTTP :80，并在 :8080 提供 Web UI。

TERMINAL — RUNSH
./pxelab
# → web ui:  http://localhost:8080
# → serving: dhcp:67 tftp:69 http:80 dns:53 nfs:2049
TIP

端口 67/69/80 需要 root 或 CAP_NET_BIND_SERVICE。在测试环境中也可以用 --dhcp-proxy 模式与现有 DHCP 服务器共存，无需改动当前网络。
