快速开始

PxeLab 是一个单二进制文件，内置 DHCP、TFTP、HTTP、DNS、NFS 五个网络服务。下载对应平台的二进制，赋予执行权限，即可在一台普通的 Linux 主机上启动完整的 PXE 引导环境。

安装并启动bash
# 下载并安装最新版本
$ curl -fsSL https://pxelab.com/install.sh | bash

# 前台启动，五个服务立即开始监听
$ ./pxelab

启动后在浏览器打开 http://<server-ip>:8080 进入 Web UI，确认 DHCP 服务状态为 running，即可让第一台客户端从网络引导。

Tip PXE 引导依赖 UDP 67/68 与 TFTP 69 端口。若主机上已有其他 DHCP 服务（如 dnsmasq、路由器自带），请先停用或使用 proxyDHCP 模式，避免租约冲突。
