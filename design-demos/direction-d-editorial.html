快速开始

PxeLab 是一个单二进制的一体化 PXE 网络引导服务器。无需安装任何依赖， 下载、运行、打开浏览器，三分钟内即可通过网络引导第一台机器。

安装

在 Linux 或 macOS 上，使用安装脚本获取最新版本。脚本会根据你的系统架构 自动选择对应的二进制文件：

Terminalbash
# 下载并安装最新版本
curl -fsSL https://pxelab.com/install.sh | bash

Windows 用户可以直接从 GitHub Releases 页面下载 pxelab.exe。所有发布产物均附带 SHA-256 校验和。

启动服务

在终端中直接运行二进制文件即可启动全部五个网络服务。首次启动时， PxeLab 会在当前目录生成默认配置文件：

Terminalbash
./pxelab
# pxelab v2.4.1 — listening on 0.0.0.0
# dhcp :67 · tftp :69 · http :8080 · dns :53 · nfs :2049
# web ui ready → http://localhost:8080
Tip

如果 67/69 等特权端口被占用，可以先以 --mode proxy 运行代理 DHCP 模式，与现有 DHCP 服务器共存，无需改动当前网络。

打开 Web UI

启动后用浏览器访问 http://localhost:8080。在 Dashboard 中可以看到五个服务的运行状态、实时引导日志，以及已发现的 客户端列表。接下来：

  1. 在 Boot 菜单 中启用一个引导条目，例如 Ubuntu 24.04 网络安装；
  2. 将目标机器设置为从网络（PXE）启动；
  3. 开机，观察它出现在客户端列表中。
