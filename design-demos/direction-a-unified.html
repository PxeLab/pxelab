快速开始

PxeLab 是一个单二进制的一体化 PXE 网络引导服务器，内置 DHCP、TFTP、HTTP、DNS、NFS 五个网络服务。无需任何外部依赖，下载即可运行，支持引导 11 种客户端架构。

在 Linux 或 macOS 上，使用安装脚本一条命令完成部署；也可以直接从 GitHub Releases 下载对应平台的二进制文件。

Terminal — bash 
# Install the latest release
$ curl -fsSL https://pxelab.com/install.sh | bash

# Start the server (Web UI on :8080)
$ ./pxelab
⇒ PxeLab v0.9.2 listening — dhcp:67 tftp:69 http:8080

服务启动后，打开浏览器访问 http://localhost:8080，在 Web UI 中启用 DHCP 服务并选择网卡，即可开始引导局域网内的第一台机器。

i
TIP

DHCP 与 TFTP 需要绑定 67/69 端口，请使用 sudo 运行，或在 Linux 上为二进制授予 cap_net_bind_service 能力。
