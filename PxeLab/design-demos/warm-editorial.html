Why PxeLab

Stop stitching five services together.

Traditional PXE deployment means separate DHCP, TFTP, NFS, and DNS servers — each configured by hand, each a point of failure. PxeLab replaces all of them.

All-in-One

DHCP, TFTP, HTTP, DNS, NFS packed into a single Go binary. One process, one config file, one web UI. No dependency hell.

Multi-Architecture

BIOS x86, UEFI x64, ARM64, RISC-V 64, LoongArch64. iPXE, PXELinux, GRUB2. Secure Boot included. One server handles them all.

Modern Web UI

React SPA with real-time logs, visual boot menu editor, host management, and REST API. Manage everything from your browser.

How It Works

Two-stage network boot

PxeLab uses a proven two-stage architecture: PXE ROM loads iPXE via TFTP, then iPXE fetches the boot menu over HTTP.

Core Modules

Six services, one interface.

Every module is configurable through the web UI, REST API, or CLI. Hot-reload means changes take effect without restart.

DH

DHCP

Three modes: Full (standalone), Proxy (PXE-only), Hybrid (default). Subnet address pools, IP reservations with MAC binding, conflict detection.

Port 67/UDP
TF

TFTP

Serves network boot programs for iPXE, PXELinux, and GRUB2. Configurable port and timeout. Architecture-aware file mapping.

Port 69/UDP
NF

NFS

Built-in NFSv3 server with multiple mount points. Per-mount IP/CIDR whitelist, read-only exports, connection tracking.

Port 2049/TCP
DN

DNS

Local DNS with upstream forwarding. Subnet-aware resolution returns the correct server IP. Auto-creates A records for the server hostname.

Port 53/UDP
UI

Web UI

React SPA with i18n (English + Chinese). Host management, boot menu editor, service monitoring, real-time log viewer with SSE.

Port 8080
CL

CLI

Full command-line management. Install as Windows service, manage config files, trigger operations programmatically.

Get Started

Up and running in three steps.

Single binary. Zero dependencies. Download, run, open browser.

01

Download

Grab the binary for your platform from GitHub Releases.

# Linux x86_64
curl -L -o pxelab https://github.com/pxelab/pxelab/releases/latest/download/pxelab_linux_amd64
02

Run

Make it executable and start. First run auto-creates config.

chmod +x pxelab
./pxelab
03

Manage

Open the web UI and configure your network boot environment.

open http://localhost:8080
