Architecture

Two-stage network boot

PXE ROM loads iPXE via TFTP, then iPXE fetches the boot menu over HTTP. Custom iPXE builds with embedded scripts — no manual configuration needed.

Full, Proxy, and Hybrid modes. Subnet pools, MAC reservations, conflict detection.

TFTP

iPXE, PXELinux, GRUB2. Architecture-aware file mapping with configurable port.

Built-in NFSv3. Multi-mount points, IP/CIDR whitelist, read-only exports.

Upstream forwarding, subnet-aware resolution, auto A-record creation.

Full command-line control. Windows service mode. Programmatic management.

Get Started

Up in three steps.

Single binary. Zero dependencies. Download, run, open browser.

01

Download

Grab the binary for your platform.

curl -L -o pxelab \
github.com/pxelab/pxelab/\
releases/latest/download/\
pxelab_linux_amd64
02

Run

Make executable and start.

chmod +x pxelab
./pxelab
03

Manage

Open the web UI.

open http://localhost:8080
