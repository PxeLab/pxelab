Why PxeLab

Five services. One binary.

Traditional PXE deployment means separate DHCP, TFTP, NFS, and DNS servers — each configured by hand. PxeLab replaces all of them.

01

All-in-One

DHCP, TFTP, HTTP, DNS, NFS packed into a single Go binary. One process, one config, one UI.

02

Multi-Architecture

BIOS x86, UEFI x64, ARM64, RISC-V 64, LoongArch64. iPXE, PXELinux, GRUB2. Secure Boot.

03

Modern Web UI

React SPA with real-time logs, visual boot menu editor, host management, and REST API.

How It Works

Two-stage network boot.

PXE ROM loads iPXE via TFTP, then iPXE fetches the boot menu over HTTP. Custom builds with embedded scripts.

Get Started

Up and running in three steps.

Single binary. Zero dependencies.

01

Download

Grab the binary for your platform from GitHub Releases.

curl -L -o pxelab \
github.com/.../pxelab_linux_amd64
02

Run

Make executable and start. First run auto-creates config.

chmod +x pxelab
./pxelab
03

Manage

Open the web UI in your browser.

open http://localhost:8080
